# 📸 Screenshot-to-Action AI

An intelligent web application that extracts actionable entities from screenshots and enables one-tap calendar, map, and task synchronization using the Gemini API.

🔗 **Live Demo:** [Try the Web App](https://swayamshoubinsahoo.github.io/screenshot-to-action-ai/)

---

## ✨ Features
* **Automated Entity Extraction:** Automatically parses tickets, receipts, itineraries, and dates from uploaded screenshots.
* **One-Tap Sync:** Quick-action buttons to add events directly to Google Calendar or view locations on Google Maps.
* **Instant Processing:** Fast client-side UI with seamless multimodal AI responses.

---

## 🛠️ Built With
* HTML5 & CSS3
* Tailwind CSS
* JavaScript
* Google Gemini API
